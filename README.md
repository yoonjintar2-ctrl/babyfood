# 이유식 식단표

월요일 시작 주간 이유식 식단표 + 냉장고 + 장보기. 둘이 같이 쓰는 초간단 사이트.

- 이번 주 · 다음 주 식단을 한 화면에 (PC) / 요일 탭 (모바일)
- 상태 3단계: **부족**(부족한 재료 표시) · **재료 준비 완료** · **완성**
  - 냉장고 재료는 날짜가 빠른 메뉴부터 차례로 배정해서 판정
- 완성 처리 시 냉장고에서 쓴 재료 차감 여부를 물어봄 (재료별 체크)
- 재료 자동완성 + 이름 갈라짐 방지: 띄어쓰기 · 오타 · 단어 순서 · 같은 뜻(계란=달걀 등) · 한 번 고른 표기는 별칭으로 기억
- 장보기: 아직 안 만든 메뉴 기준으로 냉장고에 없는 만큼 합산, `담기`로 산 재료를 바로 냉장고에

## 함께 쓰기
식단 데이터는 이 저장소의 `data/plan.json`에 저장됩니다.
기기마다 한 번, 오른쪽 위 메뉴(≡)에서 깃허브 토큰(이 저장소 Contents 읽기·쓰기)을 넣으면 연결됩니다.
연결된 기기에서 "다른 기기 연결 링크 복사"로 링크를 보내면 다른 기기도 한 번에 연결돼요.
