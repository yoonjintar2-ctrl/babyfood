# 이유식 식단표

월요일 시작 주간 이유식 식단표 + 냉장고 + 장보기. 둘이 같이 쓰는 초간단 사이트.

- 이번 주 · 다음 주 식단을 한 화면에 (PC) / 요일 탭 (모바일)
- 상태 3단계 (점·배지 색): **재료 필요**(노랑, 부족한 재료 표시) · **요리 필요**(주황) · **완성**(녹색)
  - 냉장고 재료는 날짜가 빠른 메뉴부터 차례로 배정해서 판정
- 완성 처리 시 냉장고에서 쓴 재료 차감 여부를 물어봄 (재료별 체크)
- 재료 자동완성 + 이름 갈라짐 방지: 띄어쓰기 · 오타 · 단어 순서 · 같은 뜻(계란=달걀 등) · 한 번 고른 표기는 별칭으로 기억
- 메뉴 옮기기·순서 바꾸기: PC는 끌어다 놓기(놓는 위치대로 순서, Alt/⌥ 누르고 끌면 복사) · 메뉴 창의 ↑↓로도 순서 변경
- 순서 템플릿: 메뉴 구성이 똑같은 끼니는 가장 최근에 직접 정한 순서를 기본으로 따름 · 오른쪽 위 `자동 정렬`로 전체를 그 순서로 맞춤 · 모바일은 메뉴 → `옮기기` → 칸 선택
- 메뉴 복제: 식단을 눌러 `복제하기` → 붙여넣을 칸을 클릭 (여러 칸 연속 가능, Esc/완료로 끝)
- 주마다 일자별 영양 요약 (열량·단백질·철분, 6~11개월 권장량 대비 %) · 메뉴별 "몇 끼 분량"으로 나눠 계산
- 만들 요리: 냉장고 아래에 안 만든 메뉴를 이름별로 묶어 먹을 날짜가 임박한 순으로 (지남·오늘·내일·날짜, 부족/준비 완료 표시, 누르면 메뉴 창)
- 단위 맞추기: 메뉴 재료 단위를 바꿔 저장하면 같은 이름의 다른 메뉴들도 바꿀지 묻고, 기존 양(예: 60g)별로 새 단위 값만 입력 (바꾼 비율로 미리 채움)
- 냉장고 · 장보기 · 만들 요리는 오른쪽 위 `냉장고` 버튼을 누르면 옆에서 열리는 창으로
- 단위 불일치 알림: 냉장고(예: 사과 2개)와 메뉴(예: 사과 50g) 단위가 달라 재고를 못 잡으면 상단에 알림 → 메뉴 쪽 또는 냉장고 쪽 중 하나로 일괄 환산(대략 무게로 미리 계산)
- 레시피 사진: 메뉴 창의 `사진 등록`으로 올리면 이름이 같은 요리 모든 날짜에 함께 연결 · 식단표 이름 옆 카메라 아이콘을 누르면 바로 크게 보기 (사진은 수파베이스 Storage `recipes`, 1600px로 줄여 저장) · 같은 사진(파일 내용 SHA-256 또는 파일명+크기)은 다시 올리지 않고 기존 파일을 연결 — 한 장에 여러 레시피가 있는 사진도 한 파일로 공유
- 요리 피드백: 메뉴 창·레시피 사진 창의 "만들 때 참고"에 적으면 같은 이름 요리 모든 회차에 레시피 사진 아래로 계속 표시 (수정·삭제 가능, 식단표 아이콘에 주황 점)
- 장보기: 아직 안 만든 메뉴 기준으로 냉장고에 없는 만큼 합산, `담기`로 산 재료를 바로 냉장고에
